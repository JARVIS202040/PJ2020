# PJ2020

PJ2020 is a minimal demonstration project featuring a small GUI
application written in Python using Tkinter. The goal is to provide a
simple example of how to create a graphical user interface with Python.

## Usage

1. Ensure you have Python 3 installed.
2. Run the application:

```bash
python main.py
```

A window will open displaying a greeting and a button to close the
application.

## Future development

This project may be expanded with additional widgets and functionality
to showcase more advanced Tkinter features.
